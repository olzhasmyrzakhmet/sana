## ЖЕЛЕЗНЫЕ ПРАВИЛА (выстраданы прошлым хакатоном — нарушение = провал)
1. **Правда существует только на проде.** «Тесты зелёные локально» ≠ работает. Каждый рапорт —
   с сырым выводом prod-verify с реального URL.
2. **Turso (libSQL) с ПЕРВОГО коммита.** Никакого SQLite-файла как основной БД: на Vercel он
   read-only и все записи упадут «attempt to write a readonly database». Локально — libSQL
   file:, на проде — TURSO_DATABASE_URL/TURSO_AUTH_TOKEN (скоуп Production!).
3. **Один проект Vercel.** Первым же шагом зафиксируй точное имя проекта и прод-домен; prod-verify
   бьёт ровно по нему. Расхождение «куда деплоим» ↔ «что проверяем» уже стоило нам 4 раундов.
4. **Серверные компоненты НЕ фетчат собственный API относительным URL** (на Vercel это тихое
   исключение внутри Suspense → вечный skeleton). Данные — через общие функции `lib/data/*`,
   их же используют API-роуты. `error.tsx` в каждом route-сегменте.
5. **Каждый API-роут**: zod-валидация входа, try/catch, ВСЕГДА `NextResponse.json` с телом даже
   при ошибке (никаких пустых 500). Клиент: сначала `res.ok`, тело через `text()` → безопасный парс.
6. **LLM никогда не пишет исполняемый SQL.** Он выбирает из семантического слоя → строгий
   JSON-план → zod → наш компилятор собирает SQL из whitelist-фрагментов. Это ядро продукта
   (требование ТЗ №2 «ответы на фактических данных») и главный enterprise-аргумент.
7. **AI-адаптер с fallback**: AI_PROVIDER=anthropic|mock; без ключа/сети — детерминированный mock
   (роутер канонических вопросов). Слово «mock» НЕ светится в UI и на слайдах — публично это
   «резервный режим».
8. **UI поверх графиков**: все Dialog/Popover/Dropdown с z-index выше графиковых библиотек (≥1000).
9. **Демо-доступ в один клик**: эксперт ничего не регистрирует. Кнопки «Войти как …» на /login.
   Никаких нулей в счётчиках на витрине — сид даёт живые числа.
10. **Не ломать работающее**: после каждой фазы prod-verify полностью зелёный, включая старые
    проверки. Регресс = CRITICAL.
11. Дизайн — через скилл ui-ux-pro-max / frontend-design (арт-направление в SPEC §2). Компоненты
    можно тянуть из 21st.dev MCP, если это ускоряет и вписывается в дизайн-систему.
12. Секреты: `.env` не в гите, `.env.example` с пустыми значениями. Если ключ попал в историю —
    доложи мне, сам не ротируй.
