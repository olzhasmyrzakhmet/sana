ядро доверия

LLM не пишет SQL и не видит строк

LLM получает

  • модель метрик (id, названия)
  • текст вопроса
  • уже посчитанные агрегаты

LLM НЕ получает

  • сырые строки данных
  • право писать исполняемый SQL
  • обход RBAC

Semantic Layer — источник истины. Компилятор собирает SQL из whitelist-фрагментов, значения — параметрами. Галлюцинации закрыты архитектурой, а не обещанием.
