## Структура
1. **Титул** — SANA · «Спросите свои данные» · «Ответ по данным за секунды, а не угадывание» · QR/URL.
2. **Проблема** — BI есть, инсайты у 5%; путь «вопрос → аналитик → выгрузка → дни».
3. **Решение** — 4 шага: вопрос → JSON-план → SQL → ответ+вывод.
4. **Воркспейс** — ответ: график + KPI + вывод.
5. **Ядро доверия** — Semantic Layer; «LLM не пишет SQL и не видит строк»; панель «Как посчитано».
6. **Embed** — поверх существующей BI, сниппет в одну строку.
7. **Безопасность** — RBAC (CEO vs регион), AuditLog, данные в контуре, on-prem-ready.
8. **Мультиотрасль** — 3 пака на одном ядре, новый за 30 минут.
9. **Это работает** — метрики стенда.
10. **Пилот** — «2 недели на ваших данных: доступ к витрине + 1 встреча по метрикам» + контакты.
