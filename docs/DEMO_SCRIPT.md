# DEMO_SCRIPT — SANA (5 минут)

**Стенд:** https://sana-rho-ten.vercel.app · **учётки:** ceo@demo.kz / region@demo.kz /
analyst@demo.kz, пароль demo123 (вход в один клик).

## Поминутно
**0:00–0:30 — Витрина `/`.** «BI есть у всех, но пользу извлекает 5% — аналитики. Бизнес ждёт
выгрузку днями.» Показать: на первом экране — **живой ответ из реальной БД** (не картинка):
выручка по месяцам, график, вывод, «45k строк обработано, LLM не видел сырых данных».

**0:30–1:30 — Воркспейс, CEO.** «Войти как CEO». Спросить голосом аудитории или:
«Какая выручка по месяцам за последний год?» → line + KPI + вывод с дельтой. Раскрыть
**«Как посчитано»**: план → SQL → «45 210 строк за N мс» → определения метрик →
«LLM получил модель метрик и вопрос; НЕ получал строки данных». **Это ядро доверия.**

**1:30–2:15 — Топ + follow-up + казахский.** «Топ-5 дилеров по продажам в 2026» → bar.
Кликнуть follow-up. Затем **на казахском**: «Өткен айдағы ең көп сатылған модель қандай?» →
корректный ответ. «Один движок — два языка.»

**2:15–3:00 — RBAC (гвоздь безопасности).** Выйти → «Войти как директор региона» → тот же
вопрос про топ дилеров → **данные только по Алматы** + плашка «доступ ограничен регионом».
«Тот же вопрос — разные данные. Фильтр ставит сервер, вопросом его не обойти.»

**3:00–3:40 — Мультиотрасль.** Переключить пак на **Ритейл** → «Выручка по категориям» →
работает. «3 отрасли на одном ядре. Новый пак — за 30 минут (docs/ADD_NEW_PACK.md).»

**3:40–4:30 — Embed поверх чужой BI.** Открыть `/legacy-bi` — «существующий корпоративный
дашборд Kaz-Analytics BI». Внизу справа — кнопка SANA. Нажать → задать вопрос прямо там.
Показать сниппет: **одна строка** `<script src="…/widget.js">`. «Не трогаем ваш код.»

**4:30–5:00 — Закрытие.** Витрина: карточка «SANA заметила: 3 аномалии» (провал продаж дилера,
скачок скидок бренда — детерминированно, z-score). «Готовы к пилоту на ваших данных за 2 недели:
доступ к витрине + 1 встреча по метрикам.»

## План Б (если сеть/прод лежит)
- Заранее записать экран (полный сценарий) — mp4 на ноутбуке.
- Локальный запуск: `npm run dev` против той же Turso (данные те же).
- `npm run prod:verify` показать зелёным как доказательство живости.

## Заметки
- AI-режим: если Anthropic-кредиты пополнены — `engine:anthropic` (живое понимание любых
  формулировок). Иначе — резервный режим (роутер канонических вопросов), демо-вопросы работают.
  Публично говорим «резервный режим», не «mock».
