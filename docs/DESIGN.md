# DESIGN — арт-направление SANA (реализовано в app/globals.css)

Характер: **серьёзный аналитический терминал**, не стартап-неон. Тёмная тема — основная
(данные любят тёмное). Светлая — только для embed-виджета поверх чужих BI (`.sana-light`).

## Токены (CSS-переменные, :root = тёмная)
| Роль | Значение |
|---|---|
| Фон | `#0B0F0E` |
| Поверхность-карта | `#141B19` · popover `#161E1B` |
| Текст | `#E8EDEB` · muted `#8BA098` |
| Акцент данных (линии, primary) | циан `#22D3EE` (`--data`) |
| Положительная дельта | лайм `#A3E635` (`--pos`) |
| Отрицательная дельта | крас `#F87171` (`--neg`) |
| Границы | `#223029`, тонкие 1px |
| Радиус | `0.4rem` (плотный, терминальный) |
| Палитра графиков | циан, лайм, голубой `#38BDF8`, янтарь `#FBBF24`, розовый `#F472B6` |

## Правила
- **Числа** — `.tnum` (tabular-nums + моноширинный Geist Mono).
- **Никаких радужных градиентов**, плотная сетка, 1px-границы.
- **z-index диалогов/поповеров ≥1000** (поверх Recharts) — задано в globals по `[data-slot]`.
- **Скелетон расчёта** со стадиями: понимаю вопрос → собираю запрос → считаю → формулирую.
- **Плавное появление** графика/карточки — `.sana-rise`.
- Шрифты: Geist (sans) + Geist Mono, subsets latin+cyrillic.

## Типографика (по ui-ux-pro-max §6)
- Geist (sans) заголовки/текст, Geist Mono для данных/меток/кода. Вес: 600–700 заголовки,
  400 текст, 500 метки. Моно-метки — UPPERCASE + tracking-wide (терминальный код-стиль).
- Числа всегда `.tnum` (tabular-nums) — колонки/KPI/оси не «прыгают».
- Контраст текста ≥4.5:1 (E8EDEB на 0B0F0E ≈ 13:1; muted 8BA098 ≈ 5:1).

## Лейаут витрины (data-as-hero, не «hero+3 карточки»)
1. Hero split: слева заголовок+CTA+живые счётчики, справа **реальный ответ из Turso**
   (терминальная рамка, вопрос-промпт, KPI+дельта, настоящий line-chart, вывод, «N строк»).
2. Как это работает — 4 шага с моно-сниппетами (вопрос→JSON-план→SQL→ответ).
3. Безопасность — «LLM получает / НЕ получает» + RBAC/AuditLog/контур.
4. «SANA заметила» — 3 авто-инсайта с мини-графиками.
5. Тонкая grid-текстура (44px, radial-mask) — терминальный фон, без «неонового AI-слопа».

## Графики (ui-ux-pro-max §10)
- Сетка низкоконтрастная (var(--border)), только горизонтальные линии; данные — герой.
- Палитра chart-1..5 (циан-лайм-голубой-янтарь-розовый), без тяжёлых градиентов/теней.
- Tooltip кастомный (tnum, точка серии), формат осей компактный (млн/млрд ₸).
- Тренд→line, топ-N→горизонтальный bar, доля→donut, одно число→KPI, всегда таблица-fallback.

## Анти-«AI-слоп» (do/don't)
- НЕ фиолетовые градиенты на тёмном, НЕ Inter/Roboto по умолчанию, НЕ «hero + 3 текст-карточки».
- ДА: моно-метки, tabular-числа, 1px-границы, плотная сетка, реальный график на первом экране.
- Движение 150–300ms, ease-out на входе, transform/opacity (`.sana-rise`), stagger лёгкий.
